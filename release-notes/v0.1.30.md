# v0.1.30 — Harness 0.2.2-rc.2 compatibility

- Restore plugin activation on Harness `0.2.2-rc.2` after the subagent runtime removed its previous host delivery entry point.
- Adapt member creation, queued assignments, step-boundary messages and cold recovery to the new subagent tree contract, preserving model selection, reasoning effort and tool restrictions.
- Stop selected members and their descendants without stopping unrelated siblings or closing the captain's tree. Retired members remain blocked through both model and browser messages.
- Avoid waking the captain twice after a member has already reported a completed task. Structured stop reasons preserve failure and missing-report notifications.

## 中文

- 修复 Harness `0.2.2-rc.2` 升级后插件无法启用的问题。
- 适配新版子代理的创建、任务排队、消息与冷恢复，保留成员的模型、推理力度和工具范围。
- 停止成员时清理选定分支及其后代，保留无关队员与队长；已退役成员不能通过模型或网页消息重新启动。
- 成员已回报完成结果后，不再因新版结算通知重复唤醒队长；失败或缺失回报仍会通知。

## Install

In **Plugins → Add plugin**, enter `@nanmicoder/dsh-agent-teams@0.1.30`. For a CLI-managed profile, run:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.30
```

The recommended host remains Harness `0.2.1-rc.2`. Harness `0.2.2-rc.2` joins the Ubuntu and Windows preview matrix. See the [tested matrix](../compatibility.json) and [migration evidence](../docs/harness-0.2.2-rc.2/README.md).
