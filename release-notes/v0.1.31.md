# AgentTeams v0.1.31

Harness `0.2.2-rc.5` is the recommended host. Ubuntu and Windows run the full compatibility suite for this version. The official Stable Desktop builds on Windows x64 and Apple Silicon also passed approval and task execution with two dependent members.

- Preserve a member's current task attempt when guidance wakes it, so a status poll cannot deliver the same task again. [#345](https://github.com/NanmiCoder/dsh-agent-teams/pull/345)
- Notify the captain once when a member goes idle with an unfinished attempt. [#301](https://github.com/NanmiCoder/dsh-agent-teams/pull/301)
- Reject blank task titles before writing team state and show each status flag once. [#307](https://github.com/NanmiCoder/dsh-agent-teams/pull/307), [#303](https://github.com/NanmiCoder/dsh-agent-teams/pull/303)
- Save member execution prompts supplied in inline team plans. When an edit is refused on a running plan, identify which task and member tools are still available. [#352](https://github.com/NanmiCoder/dsh-agent-teams/issues/352), [#348](https://github.com/NanmiCoder/dsh-agent-teams/issues/348)
- Search session history in batches on hosts that expose ranged snapshots, avoiding whole-log copies during member detection and mailbox handling. [#356](https://github.com/NanmiCoder/dsh-agent-teams/issues/356)

## 中文

推荐宿主为 Harness `0.2.2-rc.5`。该版本纳入 Ubuntu 和 Windows 的完整兼容测试。官方 Windows x64 和 Apple 芯片 Mac 的 Stable 桌面 Host 均通过了审批后两名成员按依赖顺序执行任务的验证。

- 指导消息唤醒成员时保留当前任务尝试，避免状态轮询重复派工。
- 成员空闲时若仍有未完成的任务尝试，队长只收到一次通知。
- 拒绝空白任务标题，避免写入无效任务。状态栏的标记只显示一次。
- 一次性建队时保存成员执行提示词。运行中的计划编辑受限时，提示还能直接调用哪些任务和成员工具。
- 支持范围读取的宿主按批查找会话事件，避免成员识别和邮件处理复制整段长会话。

## Update / 更新

For existing npm installations, open **Plugins**, check for updates, select **0.1.31**, and confirm. Follow the restart prompt if Desktop displays one. For a new installation, enter `@nanmicoder/dsh-agent-teams@0.1.31` in **Add plugin**.

已通过 npm 安装的用户，在桌面端「插件」页检查更新，选择 **0.1.31** 并确认。若应用提示重启，按提示重启。首次安装可在「添加插件」输入 `@nanmicoder/dsh-agent-teams@0.1.31`。

For standalone CLI or Web profiles:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.31
```
