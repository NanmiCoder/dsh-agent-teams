# v0.1.24 — Harness 0.2.1 compatibility

Stable AgentTeams release on npm `latest`. Recommended host: Harness `0.2.1-rc.1` (the host remains an RC).

- Support managed member activations and recursive cancellation on Harness `0.2.1-rc.1`, retaining the existing supported host versions.
- Preserve member persona and custom tool restrictions across cold recovery and plugin reloads; reject requests when required saved setup cannot be restored.
- Preserve native completion/error notifications, report deduplication and member delegation limits.
- Promote the tested `0.1.24-rc.1` implementation to a stable plugin version. No runtime behavior changes from that prerelease.

Install or upgrade:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.24
```

Restart the corresponding Harness process after installation. Host and plugin versions are independent; upgrading the plugin does not upgrade the desktop application's embedded host.

The publication workflow requires Ubuntu/Windows checks and the complete supported-host matrix. Earlier migration evidence and validation limits are recorded in [the Harness 0.2.1 migration record](../docs/harness-0.2.1-rc.1/README.md).
