# AgentTeams v0.1.21

Stable plugin release on npm `latest`. Recommended host: DeepSeek Harness `0.1.7-rc.2`, currently on its separate `next` channel. Installing AgentTeams does not upgrade the host.

- Open Team collaboration as a native workspace tab from the owning chat header or reply card. Keep member icons and conversation navigation; remove the unrelated entry from the workspace start page.
- Show task dependencies, member assignments and progress with a compact header. Fix intermediate-width column placement and use a single column in narrow panes.
- Keep team monitoring alive when its tab closes, retain completed archives, and avoid replacing file or terminal tabs. Older supported hosts retain the activity panel.
- Adapt awaited member initialization, session navigation, message producers and V4 tool-result errors to Harness `0.1.7-rc.2`. Align the development cohort and add exact `0.1.5-rc.2/rc.3` support.
- Preserve stale-report protection, report deduplication and terminal evidence without reopening work (#159), plus completion ordering and folding (#193).

## Upgrade

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.21
```

Use your active profile, restart its Harness process, and refresh the browser. Source installations must rebuild after pulling.

## Verification

Real DeepSeek model runs in isolated `/tmp` projects covered normal completion, dependency scheduling, stopping and deliberate failure. Browser checks covered chat entry points, closing/reopening, staged plans and responsive widths from 360 to 1440 pixels.
