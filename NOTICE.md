# ProjectFlow Agent Teams - Notice

ProjectFlow Agent Teams is an independently maintained derivative project based on the Agent Teams foundation originally published at:

- https://github.com/NanmiCoder/dsh-agent-teams

This project adds a lifecycle-oriented workflow for long-running software projects, persistent project context, quality gates, brownfield takeover, acceptance verification, and a redesigned user interface and interaction model.
