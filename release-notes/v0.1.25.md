# v0.1.25 — Harness 0.2.1-rc.2 installation fix

Stable plugin release on npm `latest`; recommended host: Harness `0.2.1-rc.2`.

- Fix plugin-manager installation rejection on Harness `0.2.1-rc.2`. Both `0.1.24-rc.1` and `0.1.24` omitted this host from their exact peer declarations.
- Build against the complete rc.2 dependency cohort and retain rc.1 plus all previously supported hosts.
- Add a real plugin-manager installation check without a compatibility exemption to the rc.2 runtime gate.
- Retain the member activation, cancellation, recovery and reload fixes from `0.1.24`.

In desktop plugin settings, install `@nanmicoder/dsh-agent-teams@0.1.25`, enable it, and restart the app if requested. For CLI:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.25
```

See [migration evidence](../docs/harness-0.2.1-rc.2/README.md). Host versions and plugin versions are independent.
