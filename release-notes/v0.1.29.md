# v0.1.29 — Model fallback and more reliable team status

- Restore member model fallback on Harness `0.2.2-rc.1` so a recoverable provider error can route the same work to the configured alternate model.
- Mark unfinished member tasks as failed when the model hits its output limit, so captains can retry or reassign the work. [#308](https://github.com/NanmiCoder/dsh-agent-teams/issues/308)
- Scope activity polling to the open session, reuse unchanged responses, and keep the correct snapshot across session switches. [#330](https://github.com/NanmiCoder/dsh-agent-teams/issues/330)
- Audit deliverables without blocking the host and detect changes to reviewed files even when their size and modification time stay the same. [#336](https://github.com/NanmiCoder/dsh-agent-teams/issues/336)

## 中文

- 恢复 Harness `0.2.2-rc.1` 的成员模型回退。主模型遇到可回退的错误时，成员能切换到配置的备用模型继续工作。
- 成员达到模型输出上限时，未完成的任务会进入失败状态，队长可以重试或改派。
- 活动面板按当前会话轮询，复用未变化的响应，并保留每个会话自己的快照。
- 交付物审计移到后台。即使文件大小和修改时间相同，审计仍能发现已审核文件的内容变化。

## Install

In **Plugins → Add plugin**, enter `@nanmicoder/dsh-agent-teams@0.1.29`. For a CLI-managed profile, run:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.29
```

The recommended host is Harness `0.2.1-rc.2`. Harness `0.2.2-rc.1` joins the Ubuntu and Windows CLI preview matrix. See the [tested matrix](../compatibility.json).
